# Funihh Portfolio
A personal portfolio website for **Funanani “Funihh” Netshifhefhe**, a Computer Science student from Limpopo, South Africa, interested in software and web development.

## 🌐 Live Website

Visit the portfolio: **[funihh.tech](https://funihh.tech)**

## ✨ About the Portfolio

This website is my personal space for sharing my background, skills, projects, and the work I have done while studying Computer Science.

I created it to document my progress as a developer and to have one place where people can learn more about me and the projects I am working on.

## 🛠️ Built With

* HTML5
* CSS3
* [W3.CSS](https://www.w3schools.com/w3css/)
* Font Awesome
* Google Fonts
* Formspree
* GitHub Pages

## 📌 Website Sections

* **Home** — A short introduction
* **About** — My background, skills, experience, and services
* **Projects** — Some of the projects I have worked on
* **Contact** — Contact information and a message form

## 💻 Skills

Some of the technologies and tools I have worked with include:

* HTML and CSS
* Java
* C++
* Website deployment
* Microsoft Word, Excel, and PowerPoint

I am also continuing to develop my skills in programming, data structures, algorithms, and software development.

## 📂 Project Structure

```text
funihh-portfolio/
├── index.html
├── CNAME
├── sitemap.xml
├── favicon.png
└── images/
```

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/funifrank67-coder/funihh-portfolio.git
```

Open the project folder and open `index.html` in your browser.

No build tools or additional installation are required.
